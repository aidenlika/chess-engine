# Python Chess Engine

A chess engine built from scratch in Python to explore chess move generation, legal move validation, and game-state logic. The project is currently in development, with plans to implement a search algorithm to play chess.

## Features

- Board representation and move handling
- Legal move generation and validation
- Check, checkmate, and stalemate detection
- Special move handling, including en passant and pawn promotion
- Move history and undo functionality


- **Language:** Python


### Requirements

- Python 3.x

### Installation

Clone the repository:

```bash
git clone https://github.com/aidenlika/chess-engine.git
cd chess-engine
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install any project dependencies listed in `requirements.txt`, if applicable.
